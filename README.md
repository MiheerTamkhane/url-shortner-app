# URL Shortener App

A simple and fast web application that converts long, messy URLs into short, shareable links. It helps make links cleaner, easier to remember, and convenient to share across messages, emails, and social media, while reliably redirecting users to the original URL.

## Features

- Convert long URLs into short, shareable links
- Clean and user-friendly interface
- Fast and reliable URL redirection
- Easy to share across multiple platforms

## Installation

1. Clone the repository:
```bash
git clone https://github.com/MiheerTamkhane/url-shortner-app.git
cd url-shortner-app
```

2. Install dependencies:
```bash
npm install
```
